# Карта сообщений: на какие вопросы должна отвечать документация и где

Указатель [README](README.md) построен от страницы к решаемой задаче. Этот файл устроен наоборот: единый плоский
список вопросов, на которые должна отвечать документация, где для каждого вопроса указаны раздел и страница,
отвечающие за ответ. Статус показывает, готов ли уже ответ: **Answered** (текст на
целевой странице написан), **Skeleton** (ответственная страница назначена, но содержит только заголовки),
**Gap** (нет ответственной страницы), **Off-site** (по принятому решению ответ вынесен за пределы этой документации). Меняйте статус строки на
Answered, когда на странице появляется готовый текст. Строки следуют порядку бокового меню для целевой
страницы; пробелы (Gap) размещаются там, где предположительно должна находиться страница, а строки Off-site идут в конце. Формулируйте
строки крупно (вопрос к странице, а не предложение к разделу), чтобы таблицу было легко
поддерживать.
