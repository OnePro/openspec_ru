### Создайте резервную копию пользовательского содержимого перед очисткой

Файлы, перечисленные в разделе **Файлы для удаления**, удаляются полностью. Перед подтверждением очистки создайте резервную копию всего пользовательского содержимого.

- **`openspec/AGENTS.md`**: определяется только по факту наличия; очистка не проверяет его содержимое.
- **`AGENTS.md`, `CLAUDE.md` и другие файлы конфигурации в корневом каталоге**: очистка удаляет блоки маркеров OpenSpec и сохраняет содержимое за пределами этих блоков.
- **Каталоги устаревших команд**: очистка сохраняет файлы, которые не распознаёт как сгенерированные команды.
