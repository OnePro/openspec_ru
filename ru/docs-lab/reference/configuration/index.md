# Обзор

> Все файлы и параметры, которые влияют на поведение OpenSpec, и их расположение.

| Файл | Расположение | Управляет |
| --- | --- | --- |
| [Конфигурация проекта (config.yaml)](config-yaml.md) | `openspec/config.yaml` | Схема, контекст и правила, используемые при планировании этого проекта |
| [Метаданные изменения (.openspec.yaml)](change-metadata.md) | `openspec/changes/<name>/.openspec.yaml` | Схема процесса, цель, область действия и исключения из спецификаций для одного изменения |
| [Настройки CLI (config.json)](config-json.md) | `~/.config/openspec/config.json` (в Windows путь может отличаться) | Поведение CLI openspec на вашем компьютере |
| Переменные окружения | Ваша оболочка или среда CI | Отключение телеметрии и расположение каталогов конфигурации и данных |
| Хранилища | `~/.local/share/openspec/stores/` (в Windows путь может отличаться) | Реестр и метаданные, используемые хранилищами для нескольких репозиториев |
