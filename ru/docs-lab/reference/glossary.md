# Глоссарий

> Все термины OpenSpec — по одному в строке.

OpenSpec использует слова, которые в git, CI и инструментах для агентов означают другое. В каждой строке указано значение термина в OpenSpec. Последний столбец содержит ссылки на дополнительные сведения, где они доступны.

| Термин | Определение | Подробнее |
|---|---|---|
| **Применение** | Реализация задач из предложения об изменении. Навык: `openspec-apply-change`. | [Применение изменения](skills.md#openspec-apply-change) |
| **Архивирование** | Завершение предложения об изменении: его дельты объединяются с основными спецификациями, а его папка перемещается в `openspec/changes/archive/`. | [Быстрый старт](../start/quickstart.md) |
| **Артефакт** | Документ планирования внутри предложения об изменении: `proposal.md`, дельта-спецификации, `design.md`, `tasks.md`. Не является результатом сборки. | [Артефакты](schemas/spec-driven/index.md#artifacts) |
| **Возможность** | Отдельная область поведения вашей системы. Для каждой существует одна спецификация по пути `openspec/specs/<capability>/spec.md`. | [Возможности](schemas/spec-driven/index.md#proposalmd) |
| **Предложение об изменении** | Отдельная единица работы: папка в `openspec/changes/<name>/`, содержащая артефакты планирования. Часто сокращается до «изменения». Не является коммитом git. | [Создание предложения](../start/quickstart.md#step-2-propose) |
| **Команда** | Вводимая вручную точка входа в процесс. Написание зависит от инструмента (`/opsx:propose`, `/opsx-propose`). В документации процессы вместо этого называются по навыкам. | [Поддерживаемые инструменты](supported-tools.md) |
| **Продолжение** | Создание следующего артефакта планирования для существующего предложения об изменении. Навык: `openspec-continue-change`. | [Навыки](skills.md) |
| **Способ установки** | То, как устанавливаются процессы: в виде навыков, команд или и того и другого. | [Настройка проекта](../start/setup.md) |
| **Дельта-спецификация** | Спецификация внутри предложения об изменении, в которой под заголовками `ADDED`, `MODIFIED`, `REMOVED` и `RENAMED` перечислено только то, что меняется. | [Дельта-спецификации](schemas/spec-driven/index.md#delta-specs-specmd) |
| **Исследование** | Проработка идеи с агентом до создания предложения. Код не пишется. Навык: `openspec-explore`. | [Проработка идеи](skills.md#openspec-explore) |
| **Ускоренное создание** | Создание за один проход предложения об изменении со всеми артефактами планирования, готового к реализации. Навык: `openspec-ff-change`. Не является операцией fast-forward в git. | [Навыки](skills.md) |
| **Устаревший процесс** | Команды `/openspec:*`, использовавшиеся до OPSX. |  |
| **Цикл** | Цикл, через который проходит предложение об изменении: исследование, создание предложения, рассмотрение, применение, архивирование. | [Быстрый старт](../start/quickstart.md) |
| **Основные спецификации** | Дерево `openspec/specs/`: текущее согласованное поведение вашей системы. При архивировании дельты объединяются с ним. Если у возможности ещё нет спецификации, она создаётся на основе её требований `ADDED`. | [Архивирование](../start/quickstart.md#step-5-archive) |
| **Корень OpenSpec** | Дерево `openspec/`, которое определяет команда и с которым она работает: в вашем репозитории или в хранилище. | [Хранилища](../multi-repo/stores.md#where-artifacts-get-created-when-using-stores) |
| **OPSX** | Текущая система процессов OpenSpec и устанавливаемый ею префикс команд (`/opsx:`). |  |
| **Профиль** | Какие процессы устанавливает init: `core` или `custom`. | [Профили](../customize/profiles.md) |
| **Создание предложения** | Создание предложения об изменении и генерация всех его артефактов планирования за один шаг. Навык: `openspec-propose`. | [Быстрый старт](../start/quickstart.md) |
| **Реестр** | Список зарегистрированных хранилищ на уровне компьютера, находящийся в `registry.yaml`. Не является реестром пакетов. | [CLI](cli.md#openspec-store) |
| **Требование** | Поведение, которое должна обеспечивать система; записывается с использованием SHALL: `### Requirement:` в спецификации. | [Дельта-спецификации](schemas/spec-driven/index.md#delta-specs-specmd) |
| **Сценарий** | Проверяемый пример в рамках требования, записанный в форме WHEN/THEN. | [Дельта-спецификации](schemas/spec-driven/index.md#delta-specs-specmd) |
| **Схема** | Определение того, какие артефакты создаёт предложение об изменении и в каком порядке. Не JSON Schema. | [Схемы](schemas/index.md) |
| **Навык** | Инструкции процесса, установленные там, где их считывает ваш инструмент ИИ (`.agents/skills/`, ...). | [Навыки](skills.md) |
| **Спецификация** | Файл по пути `openspec/specs/<capability>/spec.md`, описывающий текущее поведение одной возможности. | [Архивирование](../start/quickstart.md#step-5-archive) |
| **spec-driven** | Схема по умолчанию: предложение, затем дельта-спецификации, затем дизайн, затем задачи. | [spec-driven](schemas/spec-driven/index.md) |
| **Хранилище** | Автономный репозиторий OpenSpec, зарегистрированный на вашем компьютере, для планирования, охватывающего несколько репозиториев. Не хранилище данных. | [Хранилища (бета)](../multi-repo/stores.md) |
| **Синхронизация** | Объединение реализованных дельт с основными спецификациями без архивирования. Навык: `openspec-sync-specs`. | [Навыки](skills.md) |
| **Шаблон** | Начальное содержимое, которое схема предоставляет каждому артефакту. | [Схемы](../customize/schemas.md) |
| **Обновление** | В качестве навыка (`openspec-update-change`): пересмотр артефактов планирования предложения об изменении. В качестве команды CLI (`openspec update`): обновление установленных файлов OpenSpec. | [Обновление изменения](skills.md#openspec-update-change), [CLI](cli.md) |
| **Проверка** | Проверка соответствия реализации артефактам предложения об изменении перед архивированием. Навык: `openspec-verify-change`. | [Навыки](skills.md) |
| **Процесс** | Именованное действие OpenSpec (создание предложения, применение, архивирование, ...), устанавливаемое в ваш инструмент ИИ как навык или команда. | [Настройка проекта](../start/setup.md) |
| **Рабочий набор** | Личная локальная группа папок, открываемых вместе в одном инструменте. Не хранилище, и ничего не используется совместно. | [Рабочие наборы (бета)](../multi-repo/worksets.md) |
