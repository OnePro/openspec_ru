# Дельта спецификации (spec.md)

> Шаблон дельта-спецификации spec.md схемы spec-driven.

> [!NOTE]
> Шаблон из русского перевода openspec_ru (схема `spec-driven`, OpenSpec 1.15.0), не апстрим. Установка русских шаблонов: [Установка openspec-ru](/docs/ru/install).

## Шаблон

```markdown
# Дельта спецификации

## Назначение
<!-- New capabilities only: one or two sentences (50+ characters) on what this capability is for. Delete this section for an existing capability. -->

## Добавленные требования

### Требование: <!-- requirement name -->
<!-- requirement text -->

#### Сценарий: <!-- scenario name -->
- **WHEN** <!-- condition -->
- **THEN** <!-- expected outcome -->
```
