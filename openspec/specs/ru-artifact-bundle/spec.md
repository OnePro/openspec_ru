# ru-artifact-bundle Specification

## Purpose
Превращает переведённые шаблоны и схемы в дистрибутивный набор русскоязычных AI-артефактов: пререндеренные skills и slash-команды для поддерживаемых инструментов, собранные штатными генераторами апстрима и проверенные его же сборкой.

## Requirements

### Requirement: Полный перевод слоя templates и schemas

Все записи манифеста зон `templates` и `schemas` SHALL иметь RU-файлы, прошедшие детерминированную валидацию, и статус не ниже `machine`. Манифест MUST покрывать все файлы `schemas/` апстрима (включая `*.yaml`).

#### Scenario: Манифест покрывает schemas

- **WHEN** выполнен повторный seed манифеста
- **THEN** зона `schemas` содержит все файлы `schemas/` из апстрима на пинned-теге, включая `spec-driven/schema.yaml`

#### Scenario: Все templates переведены и валидны

- **WHEN** запущен `validate:ru`
- **THEN** все 19 файлов зоны `templates` и 5 файлов зоны `schemas` валидны и имеют статус `machine` или `reviewed`

### Requirement: Сборочный гейт русского overlay

Система SHALL гарантировать, что overlay `ru/**` на исходники апстрима пинned-версии собирается без ошибок (`pnpm build`) и штатные генераторы (`generate:skills`) производят артефакты с русским содержимым.

#### Scenario: Сборка RU-overlay успешна

- **WHEN** запущен build-ru после перевода всех templates
- **THEN** сборка апстрима проходит, а сгенерированные SKILL.md содержат русский текст

### Requirement: Пререндер slash-команд для поддерживаемых инструментов

Бандл SHALL содержать пререндеренные файлы slash-команд для топ-5 инструментов (Claude Code, Cursor, GitHub Copilot, Codex, Gemini CLI), сгенерированные адаптерами апстрима из RU-шаблонов, с сохранением имён команд и frontmatter-формата каждого инструмента.

#### Scenario: Команды сгенерированы для топ-5

- **WHEN** выполнена сборка бандла
- **THEN** для каждого из пяти инструментов существуют файлы команд с русским текстом тела и оригинальными именами `/opsx:*`

#### Scenario: Формат команды соответствует инструменту

- **WHEN** сгенерирована команда для конкретного инструмента
- **THEN** её frontmatter и расположение совпадают с тем, что производил бы оригинальный `openspec init` для этого инструмента

### Requirement: Версия бандла соответствует привязке

Бандл SHALL нести явную версию, равную тегу из `upstream.json`, чтобы пользователь мог проверить совместимость с установленной версией OpenSpec.

#### Scenario: Проверка совместимости

- **WHEN** патчер применяется к проекту
- **THEN** версия бандла выводится пользователю и сверяется с привязкой, при расхождении версии OpenSpec в проекте выводится предупреждение
