# Предложение

## Зачем

Существующее стороннее решение `ToruAI/openspec-ui` скрывает изменения на стадии планирования (`draft` без `tasks.md`), ломается на путях Windows (`\spec.md`), не рендерит таблицы/сценарии русского контента и требует отдельной сборки Rust-бинарника с ручным конфигом. Пользователям `openspec-ru` нужна встроенная веб-панель на русском языке, которая запускается одной командой (`openspec-ru start web`) прямо из репозитория и в реальном времени показывает канбан-доску изменений (включая этап «В проекте / Планирование») и все спецификации проекта.

## Что изменится

- Добавление команд CLI `openspec-ru start web [--port <port>] [--no-open] [--detach]` и `openspec-ru stop web`:
  - при отсутствии папки `openspec/` в целевом каталоге запуск немедленно блокируется с понятной ошибкой и кодом возврата `1`;
  - `start web` поднимает лёгкий локальный HTTP + SSE сервер (на базе встроенных модулей Node.js без внешних зависимостей), поддерживает фоновый режим `--detach` (`-d`) для запуска из сессии AI-агента без блокировки терминала и сохраняет состояние запущенного процесса (`.git/openspec-ru-web.json`) для корректной остановки через `stop web`, кнопку в веб-интерфейсе (`POST /api/shutdown`) или `Ctrl+C`.
- Добавление AI-скилла `openspec-ui` (`SKILL.md`) и slash-команды `/opsx:ui` (`/opsx-ui`) в бандл `dist-ru/` и автоустановка их патчером `applyRuPatch` во все обнаруженные инструменты проекта, чтобы пользователь мог прямо в чате сказать агенту «открой спеки» / «открой панель со спецификациями» / «закрой спеки».
- Встраивание русскоязычного веб-интерфейса на основе подготовленного дизайн-макета (`openspec-ru-ui.html`, Alpine.js + Tailwind + темная/светлая темы):
  - **Экран «Доска изменений» (Канбан)**: 5 колонок (`В проекте`, `К выполнению`, `В работе`, `Готово`, опциональная `Архив`), карточки с цепочкой 4 артефактов (`Предложение`, `Дизайн`, `Спецификации`, `Задачи` в состояниях `complete / ready / blocked`) и прогресс-баром задач;
  - **Экран «Модальное окно изменения»**: вкладки по артефактам, переключатель дельта-спецификаций, рендер таблиц, кода и чекбоксов задач;
  - **Экран «Спецификации проекта»**: двухколоночная читальня `openspec/specs/**` с фильтром, оглавлением требований `R1..Rn`, карточками `Requirement` и шагами `Scenario` (`WHEN / THEN / AND` и `КОГДА / ТОГДА / И`).
- Реализация живого обновления (`GET /api/events` SSE + `fs.watch` с дебаунсом) при любых изменениях файлов в `openspec/`.

## Возможности

### Новые возможности

- `web-ui-dashboard`: локальный read-only веб-сервер и русскоязычный дашборд (`start web` / `stop web`) для просмотра канбан-доски изменений на всех этапах (включая планирование и архив) и действующих спецификаций проекта с автообновлением в реальном времени (SSE).

## Влияние

- **Новые и изменяемые файлы**: `tools/web/` (сервер, сканер `openspec/`, шаблон UI из `openspec-ru-ui.html`, тесты), `tools/apply/cli.mjs` (подключение подкоманд `start web` и `stop web`), `package.json`, `README.md`.
- **Зависимости**: 0 новых npm-зависимостей на стороне сервера (`node:http`, `node:fs`, `node:path`).
- **Режим работы**: строго read-only по отношению к `openspec/**` (никогда не модифицирует спецификации и артефакты изменений).
