# Предложение

## Зачем

Контент сайта OpenSpec генерируется из `docs-lab/**/*.md`: именно эти страницы видит посетитель openspec.ai. В манифесте зоны `docs-lab` 42 файла (~277 КБ), из них 41 в статусе `pending` и 1 в статусе `machine` без ревью. Без этого шага «такой же сайт на русском» невозможен: переведённые UI-строки (шаг 1) поверх английской документации сайт не делают. Это шаг 2 программы «русский сайт OpenSpec».

## Что изменится

- Перевод всех 42 файлов зоны `docs-lab` в `ru/docs-lab/` через существующий пайплайн: LLM-перевод (kimi k3.1-pro) → детерминированная валидация → advisor-ревью (claude-sonnet-5-5) → статус `reviewed`.
- Доработка замечаний ревью до достижения `reviewed` по каждому файлу.
- Поведение пайплайна не меняется — это контентная работа (`skip_specs`).

## Возможности

Не изменяются (контентный шаг, `skip_specs: true`).

## Влияние

- `ru/docs-lab/` — 42 новых переведённых файла.
- `manifest.json` — 42 записи зоны `docs-lab` в статусе `reviewed`.
- Вне скоупа: лейблы сайдбара из `website/docs.sync.config.mjs`, сборка и публикация сайта (шаг 3), ревью-прогон machine-файлов других зон.
