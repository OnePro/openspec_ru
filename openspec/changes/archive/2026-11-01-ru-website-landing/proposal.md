# Предложение

## Зачем

Сайт openspec-ru.pages.dev открывался переводом документации OpenSpec, а сам проект openspec_ru был спрятан в последней секции сайдбара. Для продвижения перевода посетитель должен с первого экрана видеть openspec-ru: что это, что он неофициальный, и точную последовательность установки — от пустого проекта до русского OpenSpec. По факту выяснения порядок установки был неочевиден (блокировка без git, пин версий), а README противоречил сайту (команды без закрепления версии).

## Что изменится

- Лендинг сайта: `/` и `/docs` перенаправляются на `/docs/ru` — обзор openspec-ru; секция «OpenSpec RU» первая в сайдбаре.
- Обзор `/docs/ru` переработан: «неофициальный проект, не Fission-AI», кнопка «Установить за 4 шага», ссылка на обычную документацию.
- `/docs/ru/install` — точная последовательность шагов 0–3: git-предусловие, Node.js, установка CLI OpenSpec с пином `OPENSPEC_VERSION=v1.15.0` и проверкой версии, `npx github:OnePro/openspec_ru#v1.15.0 init`, проверка результата, разбор ошибок.
- `siteUrl` сайта → `https://openspec-ru.pages.dev` (sitemap, canonical, OG раньше указывали на openspec.dev).
- README: все команды с пином `#v1.15.0`, npm-пин `@1.15`, ссылка на сайт.
