# Proposal: bootstrap-ru-translation

## Why

OpenSpec (openspec.dev, Fission-AI/OpenSpec) полностью англоязычен: документация, AI-facing skills и slash-команды, которые `openspec init` раскладывает в проекты. Нужен русскоязычный клон — переведённые документация, skills и вебсайт, — привязанный к конкретной версии оригинала, с возможностью быстро обнаруживать и переносить апстрим-обновления в перевод. Этот change создаёт фундамент: структуру репозитория, привязку к версии апстрима и механизм обнаружения дрейфа, без которых перевод неподдерживаем.

## What Changes

- Инициализация структуры репозитория `openspec_ru` под переводческий проект (директории `ru/` (дерево-зеркало апстрима), `tools/`, `website/`, служебные файлы).
- Файл `upstream.json` с привязкой к версии апстрима: тег `v1.15.0` и commit sha.
- `manifest.json` — реестр всех переводимых файлов: путь EN-файла в апстриме, путь RU-файла, `base_blob_sha` (sha EN-файла в момент перевода), статус (`pending | machine | reviewed | outdated`), зона (`templates | schemas | docs-lab | website | meta`).
- Инструмент `tools/drift-check.mjs`: сверка blob sha каждого EN-файла из манифеста с апстримом на пинned-теге (через GitHub API, без клона), отчёт об устаревших файлах; обнаружение нового тега апстрима.
- Инструмент `tools/drift-diff.mjs`: для устаревшего файла показывает diff оригинала (EN_old → EN_new) — ровно ту дельту, которую нужно перенести в перевод.
- GitHub Actions workflow `drift.yml`: периодическая проверка (cron) новых тегов апстрима и дрейфа файлов с отчётом в issue.

## Capabilities

### New Capabilities

- `upstream-version-tracking`: привязка перевода к конкретной версии апстрима (тег + commit), манифест соответствия EN↔RU файлов с base_blob_sha и статусами, обнаружение дрейфа (sha-сверка) и получение дельты оригинала для переперевода, уведомление о новых релизах апстрима.
