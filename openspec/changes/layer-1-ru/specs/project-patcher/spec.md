# Spec Delta

## Purpose

Доставляет русскоязычные AI-артефакты в уже инициализированный проект пользователя: детектирует, какие инструменты подключены, и перезаписывает skills и slash-команды русскими версиями без изменения имён, маркеров и структуры.

## ADDED Requirements

### Requirement: Детект установленных OpenSpec-артефактов

Патчер SHALL определять, какие инструменты подключены к проекту, по наличию существующих OpenSpec-артефактов (каталоги `openspec-*/SKILL.md`, файлы opsx-команд), а не по наличию каталога инструмента вообще.

#### Scenario: Детект по существующим артефактам

- **WHEN** в проекте есть `.claude/skills/openspec-explore/SKILL.md`
- **THEN** патчер определяет инструмент Claude Code и обрабатывает его артефакты

#### Scenario: Проект без OpenSpec

- **WHEN** в проекте нет ни одного OpenSpec-артефакта
- **THEN** патчер завершается с понятным сообщением, что сначала нужен `openspec init`, и ничего не создаёт

### Requirement: Перезапись артефактов русскими версиями

Патчер SHALL перезаписывать только файлы, относящиеся к OpenSpec (skills `openspec-*`, файлы команд `opsx*`, блок AGENTS.md/CLAUDE.md между маркерами), сохраняя имена файлов, frontmatter-идентификаторы и машинные маркеры байт-в-байт. Прочие файлы проекта MUST NOT затрагиваться.

#### Scenario: Skills стали русскими

- **WHEN** патчер применён к проекту с EN-skills
- **THEN** тело каждого `openspec-*/SKILL.md` заменено русской версией, а `name:` в frontmatter и имя каталога не изменились

#### Scenario: Чужие skills не затронуты

- **WHEN** в каталоге skills инструмента есть skills сторонних пакетов
- **THEN** патчер их не изменяет

### Requirement: Идемпотентность и переприменение

Патчер SHALL быть идемпотентным: повторный запуск на уже пропатченном проекте не меняет файлы (или меняет их на идентичные) и сообщает, что всё актуально. После `openspec update`, перезаписавшего артефакты английскими, повторный запуск патчера MUST восстанавливать русские версии.

#### Scenario: Повторный запуск

- **WHEN** патчер запущен дважды подряд
- **THEN** второй запуск сообщает, что артефакты уже актуальны

#### Scenario: Переприменение после openspec update

- **WHEN** после `openspec update` артефакты снова английские и запущен патчер
- **THEN** артефакты снова становятся русскими

#### Scenario: Одношаговое обновление командой openspec-ru update

- **WHEN** пользователь выполняет `openspec-ru update` в Git-репозитории с инициализированным OpenSpec
- **THEN** команда запускает штатный `openspec update` (если CLI установлен) и сразу поверх применяет актуальный русский бандл (`skills`, `commands` и `openspec/schemas/`)

### Requirement: Отчёт о применении

Патчер SHALL выводить список обнаруженных инструментов, перезаписанных файлов и версию бандла; при отсутствии RU-версии для обнаруженного инструмента — предупреждение, что инструмент не поддерживается.

#### Scenario: Отчёт

- **WHEN** патчер завершает работу
- **THEN** выведено: инструменты, число обновлённых файлов по каждому, версия бандла

#### Scenario: Неподдерживаемый инструмент

- **WHEN** обнаружены артефакты инструмента вне топ-5
- **THEN** выведено предупреждение, файлы этого инструмента не изменены
